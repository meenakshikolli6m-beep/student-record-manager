# Student Record Manager

A simple Student Record Management System built using Python and SQLite.

## Features
- Add Student Records
- View All Students
- Search Students by Roll Number
- Update Student Details
- Delete Student Records

## Technologies Used
- Python
- SQLite
- Visual Studio Code

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run this command:

```bash
python student_records.py
```

## Purpose
This project was created to practice Python programming, database operations, and CRUD functionality.
